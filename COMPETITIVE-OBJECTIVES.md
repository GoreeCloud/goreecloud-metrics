# GoreeCloud Metrics — Competitive Objectives

## Status

Competitive objectives describe what GoreeCloud Metrics intends to learn from, match, exceed, or deliberately do differently. They are not current-feature claims.

## Primary capability reference

### Beszel

Beszel is the initial lightweight server-monitoring capability reference identified by the GoreeCloud Metrics project specification.

GoreeCloud Metrics intends to learn from the usefulness of lightweight continuous host monitoring while remaining an original first-party GoreeCloud application. Beszel is not the permanent Metrics engine, architecture, data model, interface, workflow model, or product identity.

## Objectives worth matching or exceeding

Metrics is planned to compete on:

- low operating overhead for continuous monitoring;
- clear current and historical host resource visibility;
- useful container resource visibility;
- actionable resource-health presentation rather than raw measurements alone;
- easy but secure monitored-system onboarding;
- understandable historical trends and capacity pressure;
- hardware/storage visibility where GoreeCloud requirements justify it.

## GoreeCloud-specific objectives

Metrics is intended to exceed a generic monitoring experience through substantive integration with GoreeCloud security, privacy, continuity, identity, discovery/relationship, notification, inventory, availability-monitoring, and unified administrative contexts where appropriate.

Those integrations must be independently implemented and validated; naming them here does not make them current.

## Deliberate rejections

Metrics is not intended to become a general remote shell, configuration-management system, full centralized logging platform, distributed tracing/APM platform, SIEM, Docker or Proxmox administration replacement, backup application, public status-page service, or general third-party monitoring marketplace unless future canonical requirements explicitly change that boundary.

Additional external benchmark products may be added after current evidence-based competitive research. This file intentionally does not invent a broader competitor list from memory.
